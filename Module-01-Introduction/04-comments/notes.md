# JavaScript Comments

## কী শিখলে:
কোডের ভেতর নিজের বা অন্যদের বোঝার সুবিধার জন্য কোনো ব্যাখ্যা (Note/Text) লিখে রাখাকে কমেন্ট (Comment) বলে। ব্রাউজার বা জাভাস্ক্রিপ্ট ইঞ্জিন কমেন্টগুলো এক্সিকিউট বা রান করে না, এগুলো সরাসরি এড়িয়ে যায় (Ignore করে)।

জাভাস্ক্রিপ্টে কমেন্ট লেখার দুটি নিয়ম আছে:

### 1. Single-line Comment (এক লাইনের কমেন্ট)
এক লাইনে কোনো কিছু কমেন্ট করার জন্য ডাবল স্লাশ `//` ব্যবহার করা হয়।
```javascript
// এটি একটি ভেরিয়েবল যা বয়স ধারণ করে
let age = 25;

console.log("Hello"); // এটি কনসোলে হ্যালো প্রিন্ট করবে
```

### 2. Multi-line Comment (একাধিক লাইনের কমেন্ট)
একাধিক লাইনের কমেন্ট লিখতে হলে `/*` দিয়ে শুরু করতে হয় এবং `*/` দিয়ে শেষ করতে হয়।
```javascript
/* 
এটি একটি মাল্টি-লাইন কমেন্ট।
এখানে বিস্তারিত বর্ণনা দেওয়া যায়।
সামনে আমরা ফাংশন নিয়ে কাজ করব।
*/
let score = 100;
```

**কমেন্টের ব্যবহার:**
- কোড কেন লেখা হয়েছে তা ব্যাখ্যা করতে।
- কোনো কোড সাময়িকভাবে কাজ করা থেকে বিরত রাখতে (Debugging করার সময়)। 
  যেমন: `// console.log(error);`

## প্র্যাকটিস:
* আপনার `script.js` ফাইলে `//` ব্যবহার করে একটি এক লাইনের কমেন্ট লিখুন।
* `/* ... */` ব্যবহার করে আপনার শেখার লক্ষ্য নিয়ে ৩-৪ লাইনের একটি মাল্টি-লাইন কমেন্ট লিখুন।
* একটি `console.log()` লিখে সেটিকে কমেন্ট করে দিন যাতে ব্রাউজারে সেটি আর কাজ না করে।
