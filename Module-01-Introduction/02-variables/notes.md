# JavaScript Variables

## কী শিখলে:
ভেরিয়েবল (Variable) হলো ডেটা সংরক্ষণ করার পাত্র বা কন্টেইনার। জাভাস্ক্রিপ্টে ভেরিয়েবল তৈরি বা ডিক্লেয়ার করার ৩টি প্রধান উপায় আছে:

1. **let**
   - আধুনিক জাভাস্ক্রিপ্টে (ES6) এটি সবচেয়ে বেশি ব্যবহার করা হয়।
   - `let` দিয়ে ডিক্লেয়ার করা ভেরিয়েবলের মান পরে পরিবর্তন (Re-assign) করা যায়।
   ```javascript
   let age = 20;
   age = 21; // মান পরিবর্তন করা সম্ভব
   console.log(age);
   ```

2. **const** (Constant)
   - এর মান নির্দিষ্ট থাকে, অর্থাৎ একবার ডিক্লেয়ার করলে তা আর পরিবর্তন (Re-assign) করা যায় না।
   - যেসব মান পরিবর্তন হবে না (যেমন: জন্মসাল, পাই এর মান) তার জন্য `const` ব্যবহার করতে হয়।
   ```javascript
   const birthYear = 2000;
   // birthYear = 2001; // এটি এরর (Error) দিবে
   ```

3. **var**
   - এটি পুরনো পদ্ধতি (ES5 এবং তার আগের)।
   - আধুনিক প্রজেক্টে এর ব্যবহার এড়িয়ে চলা ভালো, তবে পুরনো কোডবেসে এটি দেখা যায়।
   ```javascript
   var name = "Rahim";
   ```

**Variable নামকরণের নিয়ম (Naming Convention):**
- নাম অক্ষর (a-z, A-Z), আন্ডারস্কোর `_`, অথবা ডলার সাইন `$` দিয়ে শুরু হতে হবে।
- নামের ভেতর স্পেস থাকা যাবে না।
- জাভাস্ক্রিপ্ট Case-Sensitive (অর্থাৎ `apple` এবং `Apple` দুটি আলাদা ভেরিয়েবল)।
- সাধারণত camelCase পদ্ধতি ব্যবহার করা হয় (যেমন: `firstName`, `totalPrice`)।

## প্র্যাকটিস:
* `let` দিয়ে আপনার নাম, বয়স এবং `const` দিয়ে আপনার জন্মসাল ভেরিয়েবলে স্টোর করে `console.log()` দিয়ে প্রিন্ট করুন।
* `const` দিয়ে ডিক্লেয়ার করা ভেরিয়েবলের মান পরিবর্তন করার চেষ্টা করুন এবং কনসোলে কী Error আসে তা খেয়াল করুন।
