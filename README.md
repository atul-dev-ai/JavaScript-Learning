# JavaScript Learning Roadmap & Journey 🚀

Welcome! This repository is created to track my complete journey of learning **JavaScript**. It is structured step-by-step, starting from the absolute basics up to advanced topics and real-life projects.

## 📁 Repository Structure

The entire course is divided into multiple modules. Each module contains sub-folders based on specific topics. The general structure of a topic folder looks like this:
```text
01-hello-world/
├── index.html   # For running the code in the browser
├── script.js    # For practicing JavaScript code
└── notes.md     # A summary of what was learned in this topic
```

## 📅 Learning Phases and Modules

* **Phase 1: JavaScript Basics (Week 1)**
  * Module 01: Introduction (Variables, Data Types, Comments)
  * Module 02: Operators (Arithmetic, Assignment, Comparison, Logical)
  * Module 03: Conditions (If, Else-if, Switch)
  * Module 04: Loops (For, While, Do-while, Break, Continue)
* **Phase 2: Functions & Arrays (Week 2)**
  * Module 05: Functions (Parameters, Return, Arrow Function)
  * Module 06: Arrays (Methods, Looping)
* **Phase 3: Objects & ES6 (Week 3)**
  * Module 07: Objects (Creation, Methods, Nested)
  * Module 08: String (Methods, Template Literals)
  * Module 10: ES6 Features (Let/Const, Destructuring, Spread, Rest)
* **Phase 4: DOM Manipulation (Week 4)**
  * Module 09: DOM (Select, Events, Create Elements)
* **Phase 5: Async JavaScript (Week 5)**
  * Module 11: Async JS (Callback, Promise, Async/Await, Fetch API)
* **Phase 6: Advanced JavaScript (Week 6)**
  * Module 12: Advanced (Scope, Hoisting, Closure, 'this' keyword)
* **Phase 7: Real Projects (Week 7-8)**
  * Practical projects like Calculator, ToDo-App, Weather-App, etc., will be stored in the `Projects` folder.

*(For a detailed syllabus and practice list, please check the [learning.md](./learning.md) file)*

## 🛠️ How to Practice?
1. Navigate to a specific topic's folder and read the `notes.md` to understand the theory and rules.
2. Write your code and practice in the `script.js` file.
3. Open the `index.html` file in your browser and check the output in the Console.
