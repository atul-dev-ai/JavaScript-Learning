# JavaScript Learning Roadmap

## Phase 1: JavaScript Basics (১ম সপ্তাহ)
**শিখবে:**
* Variables (let, const, var)
* Data Types
* Operators
* Input/Output
* Conditions
* Loops

**প্র্যাকটিস:**
* Even/Odd
* Largest Number
* Calculator
* Multiplication Table
* Factorial

## Phase 2: Functions & Arrays (২য় সপ্তাহ)
**শিখবে:**
* Function
* Parameter
* Return
* Arrow Function
* Array
* Array Methods

**প্র্যাকটিস:**
* Find Largest Number
* Sum of Array
* Reverse Array
* Remove Duplicate

## Phase 3: Objects & ES6 (৩য় সপ্তাহ)
**শিখবে:**
* Objects
* Template Literals
* Destructuring
* Spread Operator
* Rest Operator

**প্র্যাকটিস:**
* Student Object
* Product Object
* Employee Management

## Phase 4: DOM Manipulation (৪র্থ সপ্তাহ)
**শিখবে:**
* getElementById
* querySelector
* Event Listener
* Form Handling
* Dynamic Element Creation

**প্রজেক্ট:**
* Counter App
* Color Changer
* Digital Clock

## Phase 5: Async JavaScript (৫ম সপ্তাহ)
**শিখবে:**
* Callback
* Promise
* Async/Await
* Fetch API

**প্রজেক্ট:**
* Random User API
* Weather App
* Movie Search App

## Phase 6: Advanced JavaScript (৬ষ্ঠ সপ্তাহ)
**শিখবে:**
* Scope
* Hoisting
* Closure
* Event Bubbling
* Event Delegation
* this Keyword

## Phase 7: Real Projects (৭ম-৮ম সপ্তাহ)
**প্রজেক্ট:**
* ToDo App
* Expense Tracker
* Quiz Application
* Weather Application
* Student Management System
* Library Management System
